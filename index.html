Normas y alcance implementado
  • ASME VIII-1:2019 UG-27(c), virolas cilíndricas, y UG-32(c), cabezal elipsoidal 2:1.
  • ASME B31.3:2018, 304.1.1 y 304.1.2, ecuación (3a), tubería recta.
  • API 650:2013, 5.6.1 y 5.6.3, método de un pie por anillo hasta 61 m.
  • ASME II-D:2019 como fuente documentada del esfuerzo admisible ingresado.
  • API 580:2016 para planificación y API 581 (enmiendas 2019–2020) para RBI. La consecuencia y el factor de daño son entradas.

La tasa CBM preliminar usa el mayor valor positivo entre largo y corto plazo. La vida remanente es (espesor actual − límite de retiro) / tasa. Las verificaciones adicionales, cargas externas, mínimos constructivos y aptitud para servicio deben ser aprobados por ingeniería.
